# Homepage Enrichment — Majestic Travels

## Context

The redesigned homepage launched with a clean teal brand direction but felt sparse: the hero was text-only, the page went straight from nav to a 6-post grid, and there was no personality or sense of place. This spec adds four improvements to fill the page with real content and visual depth.

## New Page Structure

```
NAV           teal, sticky
HERO          full-bleed photo + teal overlay + brand PNGs        ← updated
FEATURED POST most recent post, large lead card                   ← new
DESTINATIONS  5 destination cards with site photos                ← new
POSTS         search + topic pills + 3-col grid                   ← unchanged
ABOUT         circular photo + short bio + CTA                    ← new
FOOTER        dark ink + newsletter                               ← unchanged
```

---

## Section 1: Hero — Photo Background

**Change:** Add a full-bleed background image behind the existing teal overlay.

- **Default photo:** `public/site/marrakech-palm-reflection.jpg`
- **Overlay:** `rgba(14, 102, 116, 0.75)` — same teal brand colour, just translucent
- **Height:** `60vh` (up from `40vh`)
- **Implementation:** CSS `background-image` on `.site-hero` with `background-size: cover; background-position: center`
- Brand PNGs, tagline, and CTA button unchanged
- To swap photo: change one CSS line in `majestic-travels-blog.html`

---

## Section 2: Featured Post

**Change:** A large lead card auto-injected below the hero showing the most recent post.

### Layout
- Desktop: image left (~55% width) + text right — flexbox row
- Mobile (≤600px): image top, text below — flex column
- Paper (`#fff8ec`) card background, subtle shadow
- `★ FEATURED` label in teal small-caps above the title
- Title: Fraunces, ~1.8rem
- Meta: category · read time, teal, small-caps
- Excerpt: 3 lines max, Source Sans 3
- CTA link: "Read story →" in teal

### Build Script Integration
`build-blog.js` already calls `updateHome()`. Extend it to also replace a featured post anchor:

- **Anchor in HTML:** `<div id="featuredPost"></div>`
- **New function in build-blog.js:** `updateFeatured(home, posts)` — takes the first post (most recent, since posts are sorted by date descending) and replaces the anchor with the featured card HTML
- `updateHome` chain: `updateFeatured(updateHome(home, posts), posts)`

### Featured card HTML template (generated by build-blog.js)
```html
<section class="featured-section">
  <div class="featured-inner">
    <a class="featured-card" href="{url}">
      <div class="featured-media">
        <img src="{image}" alt="{imageAlt}" loading="eager">
      </div>
      <div class="featured-body">
        <span class="featured-label">★ Featured</span>
        <p class="featured-meta">{categoryLabel} · {readTime}</p>
        <h2 class="featured-title">{title}</h2>
        <p class="featured-excerpt">{excerpt}</p>
        <span class="featured-cta">Read story →</span>
      </div>
    </a>
  </div>
</section>
```

## Section 4: About

**Change:** A short personal section above the footer.

### Layout
- Desktop: circular photo (~120px) left, bio text right — flexbox row with `gap: 2rem`
- Mobile: centered column, photo on top
- Paper background, same as posts section
